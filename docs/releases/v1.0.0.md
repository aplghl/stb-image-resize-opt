# stb-image-resize-opt v1.0.0

First release. A performance fork of [stb_image_resize2](https://github.com/nothings/stb)
(`stb_image_resize2.h` v2.18) that is a **byte-identical drop-in replacement**.

- **Upstream base:** `nothings/stb` `stb_image_resize2.h` v2.18
- **Oracle sha256:** `173e654634f6ccaad98f603e686ea212eec1fe8ea6d2a5e5e8056efa10ae3880`
- **License:** MIT OR Unlicense (same as upstream)

## What it does

`src/stb_image_resize2.h` is **unchanged**. The library compiles the header twice
— a baseline (SSE2) and an AVX2 variant — with each variant's public symbols
renamed and hidden, plus a dispatch layer that exposes the canonical upstream
API (22 symbols) and selects AVX2 at runtime via self-contained CPUID/XGETBV
(no `__builtin_cpu_supports`). Baseline stays drop-in on every x86-64 CPU;
non-x86 targets build the single scalar/NEON implementation.

## Results (Intel i7-14700F, clang 23.1.2, WSL2)

| workload | speedup vs upstream `-O2` |
| --- | --- |
| Mixed suite | **+36–38% geomean** (held-out PGO; +32.8% no PGO) |
| AVX2 vs base, isolated | **+34.9% geomean** (non-half), 1.2–2.2× per row |
| sRGB regime | 1.10–1.22× |
| downstream consumer (sRGB RGBA, links the `.a`) | **1.23×** |

Run-to-run variation is a few percent. Regenerate with `make bench-vs-upstream`,
`make kernels`, `make consumer`.

## Correctness

- **8,284 differential checks × {auto, base, avx2}** byte-identical to the
  pristine oracle (5 datatypes × 14 layouts × 4 edges × 7 filters × subrects ×
  strides × splits × mixed types).
- ABI: 22 public symbols exact; internal `_base`/`_avx2` symbols hidden.
- ASan+UBSan clean (2,892 runs); non-vacuous proof; scalar/v2/v3/native/C++;
  4 cross-targets.
- `half` output falls back to baseline: pristine upstream's SSE2 and AVX2 paths
  differ in the sign bit of zero for 48 half-output filter cases.

## Known upstream quirks (documented, not fixed)

See `docs/MEASUREMENT.md`: an uninitialized read in `uint16 … WRAP … BOX`
upsample (masked by `STBIR_PROFILE`), the half signed-zero divergence, and a
UBSan false positive in the sRGB encode table lookup.

## Assets

Prebuilt static libraries plus the unchanged header for:
`x86_64-linux-gnu`, `x86_64-linux-musl`, `aarch64-linux-musl`,
`x86_64-windows-gnu`, `aarch64-macos`. The x86-64 Linux/Windows assets contain
the runtime AVX2 dispatch; other targets contain the baseline implementation.

Compile flags: `-O3 -march=x86-64-v2 -ffp-contract=off` (+ `-march=x86-64-v3`
for the AVX2 variant), held-out PGO. Include the header without the
implementation macro and link the archive.
